# Game Audio

Assigned roles: Audio worker.

## Tools and readiness

Planned local audio generator plus waveform/playback inspection; no native audio adapter connected yet.

These instructions do not install tools or grant tool access. If required evidence cannot be
obtained with the connected adapter, mark it missing and return a bounded plan or blocker.

## Workflow

Classify SFX, speech or music first; sword swings and doors are not TTS requests. Record duration, format, loop requirements, generator/license and seed when supported. Inspect actual playback, clipping, silence and loop boundaries, and test game mixing. A waveform check does not prove the sound matches the request. Report missing listening capability honestly.

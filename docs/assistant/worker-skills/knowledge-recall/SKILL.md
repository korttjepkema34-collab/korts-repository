# Knowledge Recall

Assigned roles: Every worker.

## Tools and readiness

Implemented scoped memory_search MCP or Store.search; vault read access. Automated note promotion is pending.

These instructions do not install tools or grant tool access. If required evidence cannot be
obtained with the connected adapter, mark it missing and return a bounded plan or blocker.

## Workflow

Select the project and subproject first. Search relevant terms, inspect source notes and dates, and cite note paths plus hashes where available. Resolve conflicting notes by explicit supersession and evidence, not recency alone. Do not turn a failed hypothesis into a fact. Propose a scoped note update with sources; do not place private facts in shared notes.

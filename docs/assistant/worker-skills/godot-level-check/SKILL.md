# Godot Level Check

Assigned roles: Game coder / level designer.

## Tools and readiness

Configured Godot CLI checks available through code adapter; editor MCP, playtest and screenshot integrations pending.

These instructions do not install tools or grant tool access. If required evidence cannot be
obtained with the connected adapter, mark it missing and return a bounded plan or blocker.

## Workflow

Read the pinned engine version, game design and relevant schema. Check scene/resource references, collision, spawn locations and route reachability. Run configured headless checks and the required playable scenario; inspect visible behavior when relevant. Treat successful import as only an import check. Preserve server-authoritative gameplay and document missing multiplayer/playtest evidence.

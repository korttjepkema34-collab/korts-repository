# Game Art

Assigned roles: Environment artist / sprite animator.

## Tools and readiness

Planned ComfyUI workflow adapter, image inspector and animation preview; media profiles currently block.

These instructions do not install tools or grant tool access. If required evidence cannot be
obtained with the connected adapter, mark it missing and return a bounded plan or blocker.

## Workflow

Read style references and asset dimensions. Record workflow/model/license, seed, palette, grid, transparency and intended game scale. Generate actual files through an installed adapter; inspect edges, alignment and frame consistency. For sprites, preview the animation; for environments, inspect in scene. Return files and evidence, not a text prompt represented as a finished asset.

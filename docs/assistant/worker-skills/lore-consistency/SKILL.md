# Lore Consistency

Assigned roles: Narrative worker.

## Tools and readiness

Scoped memory retrieval and supplied world/item schemas; existing text worker supports drafts.

These instructions do not install tools or grant tool access. If required evidence cannot be
obtained with the connected adapter, mark it missing and return a bounded plan or blocker.

## Workflow

Retrieve canonical names, relevant world facts, tone and stable item IDs. Separate proposed new canon from established facts. Check contradictions, length/schema constraints and duplicate names. Return draft, source-note references and any canon decision requiring review. Do not silently rewrite the world bible.

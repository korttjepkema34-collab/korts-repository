# Cloud Route

Assigned roles: Orchestrator / cloud reviewer.

## Tools and readiness

OpenRouter catalog HTTP reader; private model-card retrieval; qualified cloud invocation adapter. Discovery and ranking adapters are pending.

These instructions do not install tools or grant tool access. If required evidence cannot be
obtained with the connected adapter, mark it missing and return a bounded plan or blocker.

## Workflow

Consult ../../OPENROUTER-ROUTING.md. Match task modality, context and demonstrated skill. Keep advertised capabilities separate from measured evidence.
